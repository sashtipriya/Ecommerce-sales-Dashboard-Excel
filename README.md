# Excel Sales Dashboard

## Overview
An interactive Excel dashboard developed for sales analysis using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Key Features
- Interactive filtering using slicers
- Sales KPI cards
- Monthly sales trend
- Category-wise performance analysis
